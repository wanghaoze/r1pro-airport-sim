证据：[v5 独立指标](../../runs/isaacsim_diverse_pickplace_20261016_v5_reference/repair_result_metrics.json)、[原始结果](../../runs/isaacsim_diverse_pickplace_20261016_v5_reference/result.json)。真实 wait=1；294 帧、20 Hz，五路编码均退出0，但任务失败。

|---|---:|
| 托盘初/末 yaw | 75.0003° / 15.2238° |
| 实际桌面 Y 平移 | +21.0057 cm |
| 最大倾角 | 0.5330° |

| 失败左 TCP 目标 | [0.702348, 0.438434, 0.866678] m |

这是转动已明显发生、随后单臂目标求解失败；不能说完整 Pick 已通过、不能说托盘始终可双臂拿起，也不能由有限 IK 搜索失败推断整任务不可达。

## 源码可确认的预检缺口

1. `isaac_diverse_pickplace.supported_preadjustment(plan_only=True)` 在原中心参考上检查13个弧点；运行时 `compliant_long_axis_center` 则沿桌长轴使用真实中心。实际 +21 cm 平移不在原预检路径内。这是参考轨迹与实际执行轨迹不一致，非摩擦不足的证据。
2. `choose_supported_station` 只要求一只手的预检弧可解，选第一个成功站位；没有同时要求调盘终态的双臂下降、升起和放下路径。新规则下只能在 episode 初始化前联合选站位，不能动作中换站位。
3. `NativeTeacher.solve` 调用有限多初值 `_ik_candidates`，每次从当前实测状态/命令重新求解；离散 knot 的成功不证明连接路径连续，也不等于全路径碰撞检查。真实 PhysX 检查仍存在，本研究不建议删除。
4. `reset_released_arms` 可以改变冗余关节姿态和 IK 初值，但不会改变固定底盘与托盘的几何相对位置。它可能解决选支/初值问题，不能保证补救已平移到工作空间外的托盘。
5. 当前松手后返回待机使用关节插值；实际碰撞检查仍生效。但原地收臂前必须利用已允许的抬手撤离并检查连接路径，不能把“待机终点可达”当成“整条收臂路径可行”。

## 建议的有限私有规划研究

优先保持生产运行，不并发增加 Isaac engine。独立 CPU 规划仅操作私有 shadow 状态，绝不写真实盘 pose。

- 初始化联合变量：严格桌前 base XY/yaw、原两条长边内的抓点、已有候选 wrist pitch、调盘中心路径、满足原朝向要求的释放候选。固定 base 后整段不能改变。
- 从终态反向筛选：对每个候选真实几何位姿，先检查待机姿态→双手12 cm上方→下降→实际 lift 高度→Place 的有限连接路径；再检查单臂弧、开爪撤离、待机复位。既有多初值解应按连续关节代价连接，不能各 knot 独立选第一个解。
- 调盘中心允许的沿桌长轴运动需要同时满足“原桌面轮廓门”和“下一段单臂及最终双臂可行域”。这属于控制参考搜索，不是缩小用户验收容差。不能再次把中心硬锁死，v3/v4 已显示其可能抵消转动。
- 运行时对下一参考实际中心/yaw 做短期可达检查，并检查实际盘能否完成允许的释放→撤离→复位→双抓。满足既有朝向及完整路径即可结束准备，不追求精确0°；不能仅因为接近目标便改成功标签。
- 如果实际路径偏离预检域且找不到符合原规则的剩余路径，保留本次失败，并在新研究目录记录；不要导航、teleport、放宽角度或盲目再次尝试。

待验证的解释：待机复位可能使有限 IK 初值更好；沿边抓点调整可能降低单臂旋转时的平移耦合。两者目前均没有独立物理成功证据。

## 研究与生产出口隔离

生产可采集经全路径预检且真实完成的直接抓取多初态，记录实际覆盖范围与筛掉原因。它不代表大角度调盘鲁棒性已解决。研究源只有完整 Pick→Place、原生视频与状态控制时间闭合、原资格通过后才能进入独立后续版本；当前 v5 失败不入训练。最终 Place 分布须报告实际 Pick 末态，不能用固定持盘重置冒充泛化。

后续研究收据应至少包含：seed/parent split、初始 base 与 tray、候选与每段私有失败、真实中心/yaw、释放与桌面支撑、双臂实际初始/待机/再抓姿态、固定 base 命令、实际碰撞、全动作 span、真实进程退出码。私有规划通过与完整物理通过分报。
