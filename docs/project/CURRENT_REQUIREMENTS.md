## 独立范围

- **pickup200 / pickup120对比**：仅拿取，有独立训练来源与同父位姿留出；不等于正式整体任务的成功源。120条是完整拿取episode，不是完整三动作任务。
- **free_run_diagnostic**：600秒、20Hz真实12000帧，三个文本各200秒，只按时间切换；所有任务检查只记录，原执行器限幅保留；不计正式成功率、不进训练。
- **70%目标**：历史全场景完整任务目标，尚不能用可达性预筛数据120/120或拿取同父测试50/50宣布达标。

## 需求取舍

用户要求出现阻塞时报告：失败步骤/现象；已确认原因及证据；独立猜测；方案、影响和推荐。普通实现故障自行处理；动作流程、抓法、底盘范围、验收容差和训练方案变化等用户决策。已有授权范围可继续执行，不重复确认。
