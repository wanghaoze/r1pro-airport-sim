# v36 full400: terminal coupled IK failure audit

Source: frozen server release `releases/robust_v36_20260929/runs/completion_full400_retry3`, 400 unique scenes and 842 physical attempts. This is a read-only analysis of each scene's *last* attempt; it is not a replay or a success forecast. The machine-readable per-case evidence is `v36_coupled_ik_audit.json`, produced by `runs/control_deploy_20260929/audit_v36_coupled_ik.py`.

Of 220 unfinished scenes, 130 last attempts ended in `coupled_ik_unreachable`: front_count 1/2/3 = 24/46/60 (none in front_count 0). The failing operation was a temporary placement in 57 cases and a final-slot placement in 73. Every one of these 130 failed before any `place` physical step (`actual_duration_s=0`), after an attempted independent `transport_align` was deferred. The bounded arrival correction ran in all 130 and found zero qualified alternate bases. Thus these are predominantly placement-planning failures, not failed physical release, final stability, or contact evidence.

At the terminal coupled-IK rejection, all 130 have maximum TCP orientation error above the v36 0.05 rad planning bound: range 0.05002–0.07928 rad, median 0.05635. All 130 remain below 0.08 m maximum TCP position error (range 0.02845–0.06949 m), 0.015 m rigid-grasp position error, 0.10 rad rigid-grasp orientation error, and the configured 0.65 rad branch bound. Every recorded terminal residual is therefore *numerically within* the proposed 0.12 rad completion orientation bound. This only compares the rejected solver output with thresholds; a different bound can change IK seed selection and later paths, so it does not prove that 130 episodes will complete.

Examples: `airport_0009_20270925` temporary placement, 59.10 mm / 0.06551 rad; `airport_0018_20270934` temporary placement, 47.20 mm / 0.05896 rad; `airport_0015_20270931` final placement, 36.09 mm / 0.05175 rad. All reported position errors are under the configured 80 mm candidate bound. More records across each stratum are in the JSON audit.

The terminal residual comparison initially motivated v37's 0.12 rad loaded planning candidate. Subsequent v37 physical pilots invalidate a simple predicted gain: on original cases 7/82/310, the wider bound authorizes an earlier `transport_align` motion where v36 deferred it and completed with the combined descent. Eight independent v36 coupled-IK failures, indices 15/18/23/27/30/42/50/155, had zero completion in the early v37 priority pilot; typical new coupled-fit position errors rose to 83–94 mm, above the unchanged 80 mm ceiling. The numeric v36 residual alone does not prove that a wider IK search will return the same solution.

The v38 candidate under development is stage-scoped: keep original 0.05 rad alignment decisions, attempt the full original place plan first, and invoke a private 0.12 rad fallback only after a zero-motion pure IK planning rejection. In that private fallback, prefer the original-bound independent seed if one exists before coupled refinement, so changing the orientation acceptance ceiling does not needlessly change the seed that produced the v36 under-80-mm residual. Keep the 80 mm position, 15 mm/0.10 rad rigid grasp, 0.65 rad branch, collision, wrist, physical force/support, and final full-task checks. Actual new Episodes are required; neither the replayed thresholds nor the solver candidate selection establishes success.
