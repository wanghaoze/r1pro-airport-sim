# v27 proposed unified-spec update: normal empty-arm shortcut timing switch

`empty_arm_shortcut_headroom_enabled=True` is a boolean default-on reference-policy switch. True retains v26 normal empty-arm shortcut timing exactly. False restores only the historical v4 minimum-seconds formula for a normal empty-arm shortcut whose Cartesian IK already succeeded: `max(.15,1.875*distance/speed)`, passed to the unchanged `Runtime.joints` planner. That planner still computes its original minimum_duration from self.v/self.a/self.j, uses its existing1.12 headroom, checks swept collision/joint bounds/inverse dynamics, and executes the same tick and measured safety guards. This option does not alter any actual velocity/acceleration/jerk/effort cap or acceptance threshold.

An empty-arm endpoint fallback after Cartesian IK failure ALWAYS retains the existing additional half-v/a/j reference headroom, regardless of this switch. Loaded/contact/wrist paths, camera requirements, primitive deadlines, and all physical/final validation remain unchanged. The switch does not revert the whole controller to v4; other planning changes remain separately controlled or unchanged.

Audit event `empty_arm_shortcut_timing` records endpoint_fallback, headroom_applied, normal_headroom_enabled, original_minimum_seconds, minimum_seconds and reference-policy qualification. This is planning/reference timing metadata, not a new physical action or acceptance exception. Existing phase and episode wall/physical budgets still count actual execution; no extra excluded time is introduced.

Evidence/change record: frozen v4 and v24b case60 have identical pregrasp entry physical state at frame158. Both solve the same endpoint and choose the same free-space joint shortcut. v24b's unconditional extra half-cap headroom changes that first shortcut37→61frames and the repeated shortcut by another24frames, shifting separation push start377→425. Actual retained-contact and final geometry guard source is unchanged, and eventual new failure is real table support loss under that original guard. This warrants a controlled timing-policy comparison, not relaxing acceptance. Same environment versions and normalized scene/assets have been verified. The new switch's effectiveness is not yet physically established.
