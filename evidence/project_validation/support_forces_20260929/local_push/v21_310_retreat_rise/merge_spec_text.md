In withdraw-free push planning, original path and the existing .45/.60 alternatives run in the original order. Any accepted original/existing path is returned unchanged. Only when all three fail solely for duration, and no physical/runtime reference state has changed during planning, the option permits exactly one additional structure candidate. Input must be exactly four finite 16-column references with held columns equal to one approved 7-joint arm. Artificial point1 and following real IK point2 must be exactly equal in every non-held-arm column, including both gripper references. Unknown shape/arm layout, any inequality, any non-duration rejection, or any planning state change disables this attempt.
